Run `make run`. `vm_access` touches a bounded amount of memory page by page. Pass a size in MB (1–512) to change it. `cow_demo` allocates and touches memory, forks, and writes in the child to demonstrate copy-on-write; resource counters are process-specific and vary by system. The assignment's EAT formula is `EAT=(1-p)*ma+p*fault_service`; use seconds consistently (8 ms = 8,000,000 ns).
